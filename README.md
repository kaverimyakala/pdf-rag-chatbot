# PDF RAG Chatbot

An AI-powered PDF Question Answering system built using LangChain, Ollama, and ChromaDB.

## Features

- Load PDF documents
- Split text into chunks
- Create embeddings using Ollama
- Store embeddings in ChromaDB
- Retrieve relevant information
- Answer user questions using RAG

## Technologies Used

- Python
- LangChain
- Ollama
- ChromaDB
- PyPDF
- Vector Database
- Retrieval Augmented Generation (RAG)
